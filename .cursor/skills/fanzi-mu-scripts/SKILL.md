# 剧本与分镜

把故事写成可审阅剧本，再拆成 MiniMax H3 能逐镜生成的分镜。本 skill 只交付剧本和分镜；出视频和参考图都在 GPU 主机上完成，不要在这边调 ComfyUI。

默认在 Cursor 里打开本项目写作，这样不占用 Grok Bot 的额度。写完把文件保存回项目目录，再同步到 GPU 主机。

## 适用与边界

- 适用：新写、改写、润色短剧剧本；把剧本拆成镜头表；修订已有分镜。
- 不做：不直接调 ComfyUI、不配音、不剪辑合成、不生成参考图。
- 不要用人教同步或少儿英语动画的写法——那套规则是照课本，跟短剧相反。
- 没有授权不要直接写已有著作的原著人物、情节或独有名称；改做同类型原创故事，或先请用户确认授权。

## 核心规则

1. 先读用户已给的材料和已确定的事实。已有剧本默认保留主线、人物关系、主题和结局；未授权不要删线、合人或改结局。
2. 画幅、帧率、目标时长优先继承用户指定。都未说时：短剧默认竖屏 `9:16`、`24fps`；用户要横屏再用 `16:9`。
3. 时长先当作预算。对白、动作和停顿会重叠，逐项相加不等于成片时长。预算和内容冲突时，给出保留或压缩方案，不要提高语速或暗中删戏。
4. 单段生成时长默认按官方 H3 约束：**4–15 秒**。长对白或长动作要分段，不为凑切点多加没意义镜头。
5. **换景必换镜**。每个镜头认领本场中连续的节拍；一个节拍只能被一个镜头认领，顺序不能乱。
6. 分开写：画面内人物运动，和摄影机运动。对白逐字进镜头，不要改写成摘要。
7. 先出 1 个高曝光度样片分镜（常是第一集里最能检验角色与画风的一段），用户认可后再拆整集。
8. 未定的创作取舍给 2–3 个有差异的方案和建议，由用户决定。已授权范围直接写完。

《反字墓》还要遵守：只写原创，不用盗墓笔记或鬼吹灯的人名与独有叫法；技法只服务戏剧，不写成盗掘教程；血腥只暗示；不要新增设定里没有的司、印、碑概念。每集先过一遍设定里的创作纪律、本卷三件套和林晚的手艺阶段。

## 步骤

### 1. 定输入与范围

搞清：系列定位、本集标题、目标时长、画幅、已有角色/场景资产、本轮是写全稿还是只改一段。已有分集大纲就补写场内行动和对白；已有剧本可直接进分镜。本项目先读 `series-bible.md`、`series-outline.md` 和已有的 `vol*-scripts.md`。

### 2. 写剧本

按场次写：场标、人物、动作节拍、逐句台词、必要的旁白和情绪。台词要能念出声，动作要能看见。先交一份供人审阅的剧本（Markdown 清样），再结构化为 JSON。体例对齐已有 `vol1-scripts.md`：△ 动作、（ ）表演提示、【内行】、【笑点】、【钩】。

### 3. 拆分镜

把每个节拍认领到镜头。每镜写清：

- 时长（默认 ≤ 15 秒）
- 生成模式：有角色/场景参考图用 `Ref2VA`；有明确首帧用 `I2VA`；有首尾帧用 `FL2VA`；只有尾帧用 `L2VA`；纯文字才用 `T2VA`
- 景别、机位、运镜、画面动作、对白、光效与场景锁定
- 本镜需要的参考图（角色定妆、场景、道具）；缺图要标出，不要假装已有
- 本镜结束时的屏幕状态，便于下一镜衔接

同场景、同光照的镜头归为一批，尽量共用同一张环境参考图。分镜拼贴图只供审阅，不能当作 `I2VA` 首帧。

H3 视频提示词留给 GPU 主机上的出片流程按官方结构改写；本层只提供分镜事实、参考清单和原文台词。

### 4. 交付与确认

交付一份 Markdown 审阅稿，加一份 `script-board.json`。说清本轮范围、总时长预算、缺参考图的镜头、建议用户先看的 1–3 个重点。用户确认当前版本后，才能进入 H3 出片。打开文件或下载 JSON 算不上批准。

      "beats": [

          "action": "林晚抬起掌灯，走近石壁上的符文",
          "dialogue": [{"who": "林晚", "line": "这符文还没有人读开过。"}]
        }
      ]
    }
  ],
  "shots": [
    {
      "id": "sh01",
      "scene": "sc1",
      "beats": ["b1"],
      "duration_s": 8,
      "mode": "Ref2VA",
      "shot_size": "medium",
      "camera": "slow push-in",
      "action": "林晚举掌灯走近石壁",

校验再交付：每个 beat 被恰好一个镜头认领；镜头不跨场；单镜时长在 4–15 秒；台词与镜头一一对应；`refs` 能对上角色或场景资产。

## 交给出片管线（与 H3 QC 对齐）

分镜是流水线的 **board** 态。写完后不要假设「能生成就行」——下一棒是提示词 / 排队 / QC 门禁 / locked / 草剪（见 `fanzi-mu-h3-qc`）。

分镜里尽量标：

- `refs`：定稿资产 id（`refs/vN/`），不要写 pending
- `avoid` / `start_state`：易穿帮动作用**结构规避**写清，例如「起幅时镜已在桌上」「马勺已双手持镜，不拍递接」
- 邻镜台词归属：一句只进一镜，禁止两镜 prompt 都带同一句

### 写给 H3 出片时必须写清的动作（ep01 踩坑）

分镜 `action` / 交给「H3 出片」的事实里，下列情况要写死，否则模型会穿帮：

1. **定妆道具本镜不用**：写「本镜挎包内只有拓纸，无手镜、无圆形金属反光物；忽略定妆图上手镜」。关包、侧身走必查。
2. **拓片**：写「正看是有结构的倒刻乱笔（看得出是字），不是泼墨污点；镜读才顺」。不要只写「乱笔」。
3. **拉绳 / 吊井**：写「双手交替手拉手拉；绳只因手拉才动；手停绳停」。不要只写「绳子上来」。
4. **对白交接**：相邻两人台词在分镜里标清说话人；出字幕时按混音包络对齐，避免上一句字幕压住下一句开口。
5. **解剖 / 递物**：每人两只手；持物特写禁止第三只手；优先「已在接收者手里 / 已在桌上」起幅，不要写「递过去」的交接瞬间。
6. **英雄道具尺度**：土锈铜镜跨镜统一掌心尺（约 14–16cm）；夜市场景指定清场版参考，避免摊位多镜。

出片与草剪 QC、状态机、门禁细则见 `.cursor/skills/fanzi-mu-h3-qc/SKILL.md` 与 `pipeline/`。
